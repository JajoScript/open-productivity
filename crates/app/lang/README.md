# Traducciones

Los textos de usuario viven en `ui/strings.slint` (`@tr(...)`) y sus traducciones en `lang/<idioma>/LC_MESSAGES/open-productivity-app.po`.
Los `msgid` están en inglés; el inglés es el idioma por defecto y el idioma sigue el de Windows.
Para añadir un idioma, crea `lang/<idioma>/LC_MESSAGES/open-productivity-app.po` (copia el de `es` y traduce los `msgstr`).
